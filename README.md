# OT-ASSIGNMENT

This repository contains Python implementations of:

1. Big-M Method for solving Linear Programming Problems
2. Vogel's Approximation Method for transportation problems
3. MODI Method for optimizing transportation solutions

## Files

- `big_m_simplex.py` — Big-M method
- `transportation_vam_modi.py` — VAM and MODI methods
